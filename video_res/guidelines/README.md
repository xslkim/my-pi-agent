# 视频脚本指导方案 · 用法说明

每次写新脚本，按流水线用三套文档：

1. **动笔前** → `process-fact-baseline.md`（事实基线锁定）：把脚本要用的每个数字、行数、命令核实进事实表，写稿只准引用表内事实。
2. **写稿** → 三份写作主法**按症状选一份**（只选一份）：

   | 文件 | 方法 | 什么时候选它 |
   |---|---|---|
   | `method-goal-contract.md` | 三层目标契约 | 新系列从零起步；结构松散、内容膨胀 |
   | `method-audience-persona.md` | 受众画像先行 | 受众混杂、深浅拿不准；要出多受众版本 |
   | `method-block-design.md` | 单块单点 · 先演后讲 | 结构已定，要提高「看完能学会」的教学质量 |

3. **交构建前** → `process-av-acceptance.md`（音画预算与验收）：时长算账、视觉模式核对、逐项验收清单。

约定：

- 用法：把对应文档交给 LLM，按文档末尾「给 LLM 的提示词模板」一节填空后发令；每份文档自包含，可单独使用。
- 脚本格式规范以 AutoVideo 的 `docs/AUTHORING.md`（本机 `/home/xsl/AutoVideo/docs/AUTHORING.md`）为准。
- 五份文档的「通用底线」节逐字一致；改底线必须五处同步，改完跑 `./check-baseline.sh` 校验。
- `REVIEW-20260827.md` 是本套方案的评审存档，文中的 01–05 编号是重命名前的旧文件名（01=目标契约、02=受众画像、03=事实基线、04=单块设计、05=音画验收）。
