# NOTES — agent-user 视角改写说明

## 面向谁

日常重度使用 Claude Code / Cursor、但从没看过 agent 内部实现的程序员。讲法是「拆机评测」：每节课从他在界面上亲眼见过的现象切入（工具卡片、灰字思考、ESC 中断、匹配不唯一报错、上下文压缩、dev server 卡死），拆开给他看背后就是本课要实现的东西。

## 改写策略

- **每一集改用一个「用户侧现象」做钩子**：L1「回答为什么逐字蹦出来/丢字乱码」、L2「那个工具卡片是什么/模型绕过工具口算」、L3「Edit 报匹配不唯一/权限弹窗为什么存在」、L4「Ctrl+C 有时停不下来/Compacting 在干嘛/claude -c 续聊原理」、L5「你让 agent 起 dev server 卡死的同款事故」。课程骨架（说话→动手→改代码→好用→交付）不变，但叙事主线从「我们要实现什么」换成「你见过的 XX，根因在这」。
- **保留原课程的技术主干，删掉课程运营内容**：原文 L1 的 git 标签、验收先行、故障注入等「本课程怎么教」的元信息大幅压缩（学习者视角不关心教学法，只关心拆开看到什么）；省下的篇幅让给体验锚点和翻车根因解释。
- **修正了原文与 docs 不符的数字**：兼容层 L1 约 120 行（非 78）、pi loop 796 行对应我们 120 行（非 90）、结课总量 1200 行（非 1100），均以 docs/lessons/ 为准；run1 的表述改为「救回来后验收也全过，差别在要不要人工救援」，与 docs/runs/run1.md 一致（run1 并非未通过验收）。
- **翻车根因解释是新增的主菜**：口算绕过工具（description 缺那句「请用计算器」）、莫名 400（孤儿 tool_call_id）、ESC 停不下来（AbortSignal 没贯穿三层）、会话报废（大文件塞爆 64K）、权限确认框的存在理由（工具层挡不住，只能交给人和沙箱）——每个都先唤起记忆再给根因。
- **高亮词取舍偏向他听得懂的词**：SSE、tool_calls、agent loop、maxSteps、AbortSignal、自愈机制、兼容性税等保留高亮；偏教学内部的词（验收先行除外）少高亮；新增 CLAUDE.md、Compacting 这类他生态里的词做桥接。
- 集数保持 5 集（对应五层能力递进），但文件名按钩子重命名：lesson1-stream / lesson2-toolcalls / lesson3-guardrails / lesson4-daily / lesson5-realrun。块数 11–14 块/集，每块 3–8 行，行数不再与原版对应。
